# Audentes — pravidla webu

Tento repozitář obsahuje pravidla pro web Audentes. Text v `pravidla.md` je zatím **pracovní návrh ke schválení vedením**.

## Jak změnit pravidla

1. Otevři [pravidla.md](https://github.com/Riv3nX/audentes/edit/main/pravidla.md).
2. Uprav text přímo v prohlížeči.
3. Klikni na **Commit changes** a ulož změnu do větve `main`.
4. Web změnu načte při další návštěvě po vypršení pětiminutové mezipaměti. Správce může v administraci použít **Pravidla → Obnovit pravidla**.

Web používá adresu `https://raw.githubusercontent.com/Riv3nX/audentes/main/pravidla.md`. Zachovej název souboru a větev `main`.

## Formát Markdown

```md
## 1. Název kapitoly
Běžný text s **tučným zvýrazněním** a *kurzívou*.

- První bod
- Druhý bod

### Podkapitola
[Odkaz na Discord](https://discord.gg/audentes)
```

Z nadpisů vzniká obsah a odkazy na kapitoly. Názvy kapitol doporučujeme zachovat jedinečné. Web podporuje hledání bez ohledu na velikost písmen a diakritiku. Vložené HTML a skripty se nespouštějí.

Novinky se spravují v administraci webu, nikoli v tomto repozitáři. Při nedostupnosti GitHubu se zobrazuje poslední uložená verze pravidel.
